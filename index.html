About VEXOGA

VEXOGA is an experimental operating system designed for RISC-V architecture, enabling high-performance virtualization and cluster management...

Features

  • Cluster Management
  • Virtual Machine Management
  • Graphical User Interface (GUI)
  • Command Line Interface (CLI)
  • VM Networking
