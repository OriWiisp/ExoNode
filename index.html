About VEXOGA

VEXOGA is an experimental operating system designed for RISC-V architecture, enabling high-performance virtualization and cluster management. It simplifies managing EXOVega processor nodes and virtual machines (VMs), optimized for distributed computing tasks.

Features

Cluster Management

Control and monitor the status of EXOVega processor nodes for seamless operation.

Virtual Machine Management

Create, delete, and manage virtual machines running on the system with ease.

Graphical User Interface

A sleek, real-time dashboard for VM and cluster status monitoring.

Command Line Interface

For advanced users, manage the system via a powerful CLI.

VM Networking

Enables network communication between virtual machines in the system.
